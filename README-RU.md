Skhoron-Karnel

Ядро ОС, написанное с нуля. Лицензия: GPL-2.0-only.

Copyright (C) 2026 Skhoron.

Цель: работающая ОС на этом ядре: загрузка, память, процессы, системные вызовы, диск, файловая система, shell. Графики и оформления нет.

Принципы:

- ядро подчиняется владельцу, скрытых ограничений нет;
- идеи берутся из Linux и открытых спецификаций, код не копируется;
- языки: ассемблер, C, Rust-модули; общая граница между языками это C ABI.

Состояние на текущий момент:

- есть: структура репозитория, вход ядра (entry.S), вывод в COM1, linker script, сборка kernel.elf;
- нет: загрузчика UEFI (контракт описан в docs/boot-protocol.md), paging, прерываний, всего остального.

Сборка: make (нужны gcc и ld для x86_64). Результат: build/kernel.elf.

Документы: docs/principles.md, docs/boot-protocol.md, docs/ideas.md, docs/sources.md.
