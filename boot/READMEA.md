# boot/

Здесь будет собственный загрузчик UEFI x86_64. Сейчас его нет.

Что он должен сделать: найти `kernel.elf` на ESP, разложить сегменты в память, построить таблицы страниц с ядром в higher half, получить memory map, `ExitBootServices`, передать управление в `_start` с указателем на `struct boot_info` в `%rdi`.

Формат передачи данных: `docs/boot-protocol.md` и `include/skhoron/boot_info.h`.

Secure Boot: на ноутбуках с включённым Secure Boot неподписанный загрузчик не запустится. Либо отключить его в прошивке, либо подписать загрузчик своим ключом, записанным в прошивку.
