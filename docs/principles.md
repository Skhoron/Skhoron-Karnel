# Принципы

1. Ядро подчиняется владельцу. Нет принудительного lockdown, обязательной подписи модулей, телеметрии, удалённого отключения. Механизм прав (uid, capabilities) нужен для изоляции процессов, но политику задаёт владелец и может её отключить.
2. Код пишется с нуля. Идеи берутся из Linux и из открытых описаний (Intel SDM, UEFI, POSIX, osdev). Код Linux не копируется и не переписывается построчно.
3. Языки: ассемблер (вход, переключение контекста, заглушки прерываний), C (ядро), Rust (драйверы, файловые системы, разбор протоколов). Граница между языками это C ABI: `extern "C"`, `#[repr(C)]`.
4. Лицензия: GPL-2.0-only. В начале каждого файла строка `SPDX-License-Identifier: GPL-2.0-only`.
5. Объём: загрузка, память, процессы, системные вызовы, диск, файловая система, shell. Графический интерфейс и оформление не входят.
6. Пределы: прошивка UEFI, Intel ME / AMD PSP и закрытые прошивки устройств работают ниже ядра и ядром не контролируются.
